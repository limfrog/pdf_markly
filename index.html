📘 PDF Markly 사용설명서
PDF Markly는 PDF 페이지 위에 텍스트, 음악 기호, 도형, 필기와 형광펜을 추가하고 레이어 단위로 관리한 뒤 PDF·PNG·PMF로 저장하는 편집 도구입니다. 아래 순서대로 보면 처음 사용하는 경우에도 바로 작업할 수 있습니다.

🚀 빠른 시작

  1. 파일 → PDF 열기에서 편집할 PDF를 엽니다. 이전 작업을 계속하려면 PMF 열기를 사용합니다.
  2. 오른쪽 레이어 패널에서 작업할 레이어를 선택합니다. 선택된 레이어가 새 객체가 들어갈 위치입니다.
  3. 그리기 탭에서 텍스트, 도형, 연필, 형광펜 등을 선택해 페이지에 입력합니다.
  4. 선택 도구로 객체를 누른 뒤 드래그해 이동하고, 주변 핸들을 드래그해 크기를 조절합니다.
  5. 편집을 계속할 파일은 PMF 저장, 최종 배포본은 PDF 저장을 권장합니다.
권장 작업 방식 — 중요한 문서는 중간중간 PMF로 저장해 두면 레이어, 객체 위치, 편집 상태를 그대로 다시 열 수 있습니다.

🖥️ 화면 구성

왼쪽 · 페이지 목록PDF의 각 페이지를 썸네일로 표시합니다. 원하는 페이지를 눌러 이동합니다.
가운데 · 캔버스A4 편집 캔버스입니다. PDF 원본 내용과 Markly 객체를 분리해 편집합니다.
오른쪽 · 레이어현재 페이지의 레이어와 각 레이어 안의 객체를 관리합니다.
상단 · 리본 메뉴파일, 그리기, 보기, 도움말 기능을 탭별로 제공합니다.

📄 PDF 내용 크기·위치 조절

PDF를 열면 편집 캔버스는 A4 크기로 유지되고, 원본 PDF 내용은 캔버스 안의 별도 영역으로 배치됩니다. 보기 → PDF 내용에서 원본 내용만 확대·축소하거나 이동할 수 있습니다.

  • 내용 조절을 누르면 PDF 내용 테두리와 모서리 핸들이 나타납니다. 테두리를 드래그하면 이동하고, 모서리 핸들을 드래그하면 비율을 유지한 채 크기를 조절합니다.
  • − / ＋ 또는 퍼센트 입력으로 최초 맞춤 크기를 기준으로 20~300%까지 조절할 수 있습니다.
  • 맞춤은 처음 불러왔을 때의 크기와 중앙 위치로 복원하고, 가운데는 현재 크기를 유지한 채 중앙 정렬합니다.
  • 화살표 버튼은 PDF 내용만 5px씩 이동합니다. Markly에서 새로 만든 텍스트·도형·필기는 그대로 유지됩니다.
  • PDF 원본에서 가져온 주석은 원본 내용과 함께 이동·확대·축소됩니다.
편집 화면의 PDF 배경은 이전보다 높은 해상도로 렌더링됩니다. 일반 PDF 저장 시에는 화면용 이미지가 아니라 원본 PDF 페이지를 벡터로 다시 배치하므로 원본 품질을 유지합니다.

🖱️ 선택·이동·크기 조절

  • 선택 도구(V)로 객체를 누르면 파란 선택 테두리와 8개의 크기 조절 핸들이 나타납니다.
  • 선택한 객체를 드래그하면 이동합니다. 방향키는 1px, Shift + 방향키는 10px씩 이동합니다.
  • Shift + 클릭 또는 빈 공간을 드래그하는 방식으로 여러 객체를 함께 선택할 수 있습니다.
  • 핸들을 드래그하면 사각형·원·선·이미지·텍스트 등 선택한 객체의 크기를 조절할 수 있습니다.
  • Ctrl/Cmd + C, V, D로 복사·붙여넣기·복제가 가능합니다.
  • 잠긴 레이어의 객체나 숨긴 레이어의 객체는 캔버스에서 편집되지 않습니다.

✏️ 그리기 도구

텍스트 (T)페이지를 눌러 글자를 입력합니다. 글꼴, 크기, 굵게·기울임·밑줄, 박스 텍스트 옵션을 사용할 수 있습니다.
도형 / 음악 기호 (M)높은음자리표·낮은음자리표·조표·음표·쉼표·반복기호와 붙임줄, Shuffle 1·2 등을 삽입합니다.
선 · 사각형 · 원 · 화살표클릭 후 드래그해 그립니다. 전경색은 선/테두리, 배경색은 채우기에 사용할 수 있습니다.
오선드래그한 폭에 맞춰 5선 오선을 만듭니다. 선 두께 설정도 함께 적용됩니다.
연필 · 지우개 · 형광펜자유 필기, 지우기, 반투명 형광 표시를 합니다. 형광펜은 배경색과 배경 투명도를 사용합니다.
색상 · 투명도전경색은 선·글자·테두리, 배경색은 형광펜·도형 채우기 등에 사용합니다.

마디줄 기능

선 또는 오선 도구를 선택하면 마디줄 체크가 나타납니다. 체크한 상태로 새 선/오선을 그리면 길이의 1/4, 2/4, 3/4, 끝점에 마디줄 4개가 함께 생성됩니다. 직선은 주 선에 직각으로, 오선은 5선을 가로질러 표시됩니다.

붙임줄 / Shuffle

도형 목록의 붙임줄 위·아래, Shuffle 1·2는 이미지형 도형으로 삽입됩니다. 삽입 후에는 일반 객체처럼 이동, 크기 조절, 복제, 레이어 이동이 가능합니다.

▱ 레이어 사용법

  • 레이어는 페이지(캔버스)마다 독립적으로 관리됩니다.
  • 상단 ＋ / −로 레이어를 추가·삭제하고, ↑ / ↓로 레이어 순서를 변경합니다.
  • ◉ / ○ 버튼으로 레이어를 보이기/숨기기 할 수 있습니다. 숨긴 레이어는 화면과 PDF·PNG 출력에서 제외됩니다.
  • 🔓 / 🔒 버튼으로 레이어를 잠그거나 해제합니다. 잠긴 레이어의 객체는 이동·삭제·크기 조절할 수 없습니다.
  • 레이어 이름을 더블클릭하면 이름을 변경할 수 있습니다.
  • 각 레이어 아래에는 포함된 객체 목록이 표시됩니다. 객체 행의 ↑ / ↓는 같은 레이어 안의 앞뒤 순서, ✕는 삭제입니다.
  • 객체를 선택한 뒤 대상 레이어의 ⇥ 버튼을 누르면 선택 객체를 그 레이어로 이동합니다.
레이어 목록에서 위쪽에 있는 레이어일수록 화면에서도 앞쪽에 표시됩니다.

💾 저장 형식과 페이지 관리

PDF 저장일반적으로 공유하거나 인쇄할 최종 PDF를 만듭니다. 저장 시 용량 옵션을 선택할 수 있습니다.
표준 주석 PDF가능한 주석을 PDF 표준 주석 형태로 저장해 다른 PDF 프로그램에서도 주석으로 인식·수정할 수 있도록 합니다.
PNG 저장현재 페이지만 하나의 PNG 이미지로 저장합니다.
PMF 저장레이어, 객체, 편집 상태와 원본 PDF 정보를 보존하는 PDF Markly 프로젝트 형식입니다.

페이지

페이지 추가로 빈 페이지를 추가하고, 페이지 삭제로 현재 페이지를 제거합니다. 왼쪽 페이지 목록을 눌러 페이지를 전환합니다.

📱 모바일 사용법

  • 화면 상단의 페이지 버튼과 레이어 버튼으로 좌우 패널을 열고 닫습니다.
  • 한 손가락은 선택·이동·그리기·핸들 크기 조절에 사용합니다.
  • 두 손가락 핀치는 확대/축소, 두 손가락 드래그는 확대된 캔버스 이동에 사용합니다.
  • 도형을 선택한 뒤 파란 핸들을 손가락으로 잡아 드래그하면 크기를 조절할 수 있습니다. 실제 터치 판정 영역은 보이는 핸들보다 크게 설정되어 있습니다.
  • 레이어 패널의 객체별 ↑ / ↓ / ✕ 버튼도 모바일에서 누르기 쉽도록 큰 터치 영역을 사용합니다.
