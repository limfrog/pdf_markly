개인정보처리방침

PDF Markly

최종 수정일: 2026년 10월 29일

1. 기본 원칙

PDF Markly는 사용자가 불러온 PDF·이미지·PMF 문서의 내용을 개발자 서버로 업로드하거나 저장하도록 설계되어 있지 않습니다. 문서 편집은 사용자의 브라우저 안에서 처리됩니다.

본 방침은 PDF Markly(이하 “앱”)가 처리하는 정보와 외부 통신, 저장 방식을 설명합니다.

2. 앱이 처리하는 정보

  • 사용자가 직접 선택한 문서 — PDF, 이미지, PMF 파일 및 문서 안에 사용자가 추가한 텍스트·도형·필기·주석 등
  • 앱 설정 — 테마 설정 및 업데이트 확인 시각 등 최소한의 환경 정보가 브라우저 저장소(localStorage)에 저장될 수 있습니다.

앱은 회원가입이나 자체 계정 로그인을 요구하지 않으며, 이름·전화번호·주소와 같은 개인정보를 개발자에게 제출하도록 요구하지 않습니다.

3. 문서 데이터의 저장 및 전송

  • 불러온 문서와 편집 내용은 브라우저 메모리에서 처리됩니다.
  • PDF, PNG, PMF 등의 결과 파일은 사용자가 저장 기능을 실행했을 때 사용자의 기기로 내려받거나, 지원되는 모바일 환경에서는 사용자가 선택한 공유 대상으로 전달됩니다.
  • 최근 파일 — 저장한 PDF·PNG·PMF 결과의 사본과 파일명·저장 시각을 브라우저 저장소(IndexedDB)에 최대 10개 보관하여 다시 열 수 있게 합니다. 같은 이름의 사본은 최신 저장본으로 교체됩니다. 이 사본은 개발자 서버로 전송되지 않습니다.
  • 앱 자체에는 사용자의 문서 내용을 Horizon Entertainment의 서버로 전송·보관하는 기능이 없습니다.

4. 외부 서비스 및 네트워크 요청

앱 기능 제공을 위해 다음 외부 서비스에 네트워크 요청이 발생할 수 있습니다.

  • cdnjs.cloudflare.com — PDF.js, pdf-lib, jsPDF 등 실행 라이브러리 로딩
  • fonts.googleapis.com / fonts.gstatic.com — 선택 가능한 웹폰트 로딩
  • api.github.com — 앱의 새 버전 확인

이 요청에 사용자가 편집 중인 PDF 또는 문서 내용이 포함되도록 구현되어 있지 않습니다. 다만 외부 서비스 제공자는 접속 과정에서 IP 주소, 브라우저 정보 등 일반적인 접속 로그를 자체 정책에 따라 처리할 수 있습니다.

5. 쿠키·광고·분석

PDF Markly 자체는 광고 목적의 사용자 프로파일링이나 행동 분석 기능을 포함하지 않으며, 앱 기능을 위해 별도의 추적 쿠키를 생성하지 않습니다.

6. 데이터 보관 및 삭제

문서 데이터는 앱이 개발자 서버에 보관하지 않으므로 개발자가 별도로 삭제할 서버 저장본이 없습니다. 사용자는 저장한 PDF·PNG·PMF 파일을 본인의 기기에서 직접 관리·삭제할 수 있습니다.

최근 파일 사본은 앱의 ‘파일 → 최근 파일 → 목록 비우기’에서 삭제할 수 있습니다. 최근 파일 사본, 테마 및 업데이트 확인 정보와 같은 브라우저 저장 데이터는 브라우저의 사이트 데이터 삭제 기능으로도 제거할 수 있습니다. 최근 파일 사본을 삭제해도 기기에 내려받은 파일은 삭제되지 않습니다.

7. 아동 및 민감정보

앱은 특정 연령대의 개인정보를 수집하도록 설계되지 않았습니다. 사용자가 문서 안에 개인정보나 민감정보를 직접 입력하는 경우 해당 정보의 적법한 취급과 보관 책임은 사용자에게 있습니다.

8. 방침 변경

앱 기능이나 데이터 처리 방식이 변경되면 본 개인정보처리방침을 함께 갱신합니다. 변경된 내용은 이 페이지의 최종 수정일로 확인할 수 있습니다.
